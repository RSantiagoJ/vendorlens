COMPANY OVERVIEW
Paylocity is a cloud-based payroll and HCM software company focused on mid-market
organizations, known for its modern user interface, strong employee self-service
capabilities, and rapid product innovation.
Headquarters: Schaumburg, IL. Founded: 1997. Employees: 6,500+.
Publicly traded: PCTY (NASDAQ). Annual revenue: ~$1.1B (FY2025).
Paylocity primarily serves organizations from 20 to 5,000 employees, with growing
presence in the 5,000–10,000 segment. Higher education is a stated growth vertical.

LIABILITY

CORE PAYROLL FUNCTIONALITY
Paylocity Web Pay handles multi-frequency payroll for most standard employee types
with a modern, intuitive interface. Some advanced higher education-specific features
require workarounds.

Pay frequencies and employee types:
- Weekly, biweekly, semi-monthly, and monthly in single tenant
- All employee types supported at flat PEPM rate (no tiering)
- Faculty 9/10/12-month spread pay: supported via custom earnings code configuration
  (requires implementation configuration; not out-of-box for all contract structures)
- Graduate assistant stipend processing: supported; tuition waiver tracking not native
  (requires manual tracking outside Paylocity or custom integration)
- Student workers and casuals: fully supported
- Retroactive pay: supported within same pay period; cross-period requires off-cycle run

Garnishments:
- Child support, tax levies, creditor garnishments, student loan garnishments
- Per-transaction fee: $9.75 per garnishment event
- Automated priority calculation included; state income withholding registration
  managed by Paylocity for included states
- Bankruptcy garnishment processing: requires manual configuration; support available

Tax filing:
- Federal: 940, 941, W-2, 1099-NEC, 1099-MISC, ACA 1095-C (1095-C as add-on)
- Multi-state: 5 states included in base; $480/state/year above that
- Local payroll tax: supported for major localities; less common local jurisdictions
  may require manual filing by institution
- New hire reporting: automated for all 50 states
- Paylocity bears penalty liability up to $50,000 aggregate per year for Paylocity errors
  (note: aggregate cap creates risk for large or complex payroll operations)

Employee self-service (Paylocity Mobile + Web):
- Pay stub access: current and history (limited to tenure at this employer)
- W-2 and 1099 electronic delivery and download; prior-year available
- Direct deposit: up to 3 accounts; update effective next pay cycle
- W-4 and state tax withholding updates: available in self-service
- Personal information updates: available
- Mobile app (iOS and Android): full feature parity for self-service (pay stubs, W-2,
  direct deposit, time off requests if Time module is included)
- Access without institutional email: not currently supported;
  separated employees must contact HR to retrieve documents

INTEGRATIONS
HRIS/HCM: Paylocity is typically deployed as a combined payroll + HRIS. Integration with
  external HRIS via Paylocity Marketplace. Workday HCM: certified connector ($6,500/year).
  Oracle HCM: SFTP flat-file (no certified connector). Ellucian Banner: SFTP flat-file
  (institution-configured; no native connector or professional services support from Paylocity).
Time and attendance: Native Paylocity Time module (add-on). Third-party time systems:
  SFTP import only; no real-time API integration available for third-party time.
GL/Accounting: GL file export; configurable chart-of-accounts mapping.
  Native connectors: QuickBooks, Sage Intacct, NetSuite. Oracle and Workday Financials:
  SFTP export with manual mapping (no certified connector).
  Banner Finance: requires custom SFTP setup by institution.
Benefits: Paylocity Benefits module (add-on); EDI 834 exchange with major carriers;
  some regional carriers may require manual enrollment.
SSO: SAML 2.0 supported; tested with Azure AD and Okta; Shibboleth not tested
Open API: REST API available; read-only for most endpoints; write access in beta
